CoralCraft portable mode

While this file sits next to coralcraft.exe, CoralCraft keeps its preferences, swatch and
graphic style libraries, added fonts, crash-recovery files and logs in the CoralCraftData folder
beside it, and writes nothing to %APPDATA%. Copy the whole folder to move CoralCraft with its
settings. The first time CoralCraftData is created, any settings already in
%APPDATA%\CoralCraft are copied into it; the originals are left where they were.

Keep this folder somewhere only you can write to: whoever can write here decides your settings,
including the plug-ins and fonts folders CoralCraft loads from, and the Data Recovery copies of
your unsaved documents are kept here too.

Delete this file to use the normal per-user settings folder (%APPDATA%\CoralCraft) instead.
If CoralCraftData can't be written (for example on a read-only drive), CoralCraft logs a
warning and uses %APPDATA%\CoralCraft instead.
