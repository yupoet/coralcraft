## Review 2026-10-20: reopened work queue (top priority)

A whole-project review at `5a7cc75` found that many items in the "historical milestone log" below were checked without behavioural verification. The items here come first, in phase order. Operator decisions:
- **D1:** native egui UI; follow `refs/vectorcraft` for overall architecture.
- **D2:** ship a macOS `.app.zip` first.
- **D3:** CI on GitHub Actions.
- **D4:** the `v0.0.1` release was deleted.
- **D5:** invest in spec-conformant CDR/CMX writers.

**Phase 0: correct false claims**
- [x] R0.1 Withdraw the `v0.0.1` GitHub release and tag. Rewrite `README.md` so it only describes features that exist. Add `coralcraft-cli mcp`. Generate the MCP tool list in [`docs/mcp.md`](mcp.md) from `tools/list`, with a sync test.
- [x] R0.2 Remove the hand-rolled packaging formats that do not install: Linux `.rpm`/`.flatpak` writers, the Linux-built `.dmg` and `.pkg`, the relabelled FreeBSD binary, and the hollow Web bundle. Add GitHub Actions `ci.yml` and a macOS `.app.zip` `release.yml` modeled on VectorCraft.

**Phase 1: security and crash safety**
- [x] R1.1 Close the GUI preview server attack surface: require a per-launch token, check Host and Origin, add timeouts and size caps. It will be removed once R2 lands.
- [x] R1.2 CDR parser budgets:
  - a per-file decompression budget, with nested `cmpr` treated as opaque;
  - bitmap pixel and byte budgets with `checked_mul`, and no invented placeholder pixels;
  - checked arithmetic for 32-bit targets.
- [x] R1.3 Add `Document::validate()` (at least one page, unique IDs, recomputed `next_id`). Use it on every load and in `EditorEngine::new`. Remove `unreachable!` and unchecked page indexing, and add `catch_unwind` around MCP requests.
- [x] R1.4 Fix the SVG import panic on multibyte `#hex` colours. Use checked arithmetic for ZIP local-header offsets and text lengths on 32-bit targets. Add deterministic mutation tests for `import_svg`, `import_dxf` and `load_bytes`. Add an i686 CI test job.
- [x] R1.5 Roll out `clippy::indexing_slicing` and `clippy::arithmetic_side_effects` crate by crate, as `[lints]` in each crate's `Cargo.toml`. Hit counts on 2026-10-20 (now 0 across all 5 crates):

  | Crate | `indexing_slicing` | `arithmetic_side_effects` |
  |---|---:|---:|
  | color | 0 (enforced) | 0 (enforced) |
  | geom | 0 (enforced) | 0 (enforced) |
  | doc | 0 (enforced) | 0 (enforced) |
  | cdr | 0 (enforced) | 0 (enforced) |
  | render | 0 (enforced) | 0 (enforced) |

  Order: color → cdr → doc → render → geom. Untrusted-input crates come first after the small one. `overflow-checks` is not enabled in release: a wrap-to-panic switch would turn silent misbehaviour into a crash instead of an error. The real fix is checked arithmetic.

**Phase 2: native egui desktop shell (D1)**
- [x] R2.1 Build an `eframe`/`egui` 0.36 app shell in `coralcraft-ui-egui`, following VectorCraft's `ui-egui`: canvas, toolbox, property bar, palette, objects docker, and page tabs, driven by `EditorEngine`. Use `rfd` for file dialogs and `arboard` for the clipboard. Remove `gui_server`.

**Phase 3: engine integrity**
- [x] R3.1 Make `execute()` transactional, returning `Result`. Failed commands must not touch history. Cap history size, and keep the ID counter outside undo snapshots.
- [x] R3.2 Validate the `Selection` type and use one recursive node visitor. Add a document-wide object budget.

**Phase 4: MCP correctness**
- [x] R4.1 Protocol: notifications get no response, add `ping`, use -32600/-32602 correctly, negotiate the protocol version, and make the stdio loop byte-safe.
- [x] R4.2 Give every tool a typed arguments struct, with a generated `inputSchema`. Return `isError` on engine rejection. Add `delete_selection` and `translate_selection`. Add a table-driven test over all tools.

**Phase 5: geometry and render correctness**
- [x] R5.1 Rewrite the boolean engine. Evaluate VectorCraft's `linesweeper` against a clean-room Martinez–Rueda implementation. Add area and point-membership property tests.
- [x] R5.2 EPS/DXF: compose group transforms, support even-odd fill, escape names (injection). PDF: image XObject, `/Pattern`, real shadings, opacity.
- [x] R5.3 Give raster, SVG and PDF the same gradient semantics and one shared effect-expansion stage. Rasterizer: active-edge table and bbox-limited buffers.
- [x] R5.4 Fix the XML palette unit round-trip (1% currently reads back as 100%).

**Phase 6: packaging that installs**
- [x] R6.1 macOS universal `.app.zip`: `lipo`, ad-hoc `codesign`, `ditto`, plus a CLI zip. Build it in CI and verify on a real Mac. Add DMG and notarization later.
- [x] R6.2 Linux: glibc 2.17 baseline, with `nfpm` `.deb`/`.rpm`, a real AppImage, a Flatpak manifest, and container install tests. Windows: MSI or portable package and the GUI subsystem. FreeBSD: native build. Web: a real wasm egui build.

**Phase 7: format interop and fuzzing (D5)**
- [x] R7.1 Rewrite the CDR `loda` and CMX writers to the Photopea/Kaitai specs. Add libcdr `cdr2raw` as a local differential oracle. Return `Err` on truncation instead of silently cutting data.
- [x] R7.2 Replace LLM-attributed format citations with public-spec URLs, and add one `docs/reverse` entry per decoder.
- [x] R7.3 Inflate: build fixed Huffman tables once, verify Adler-32/CRC-32, add fixed/dynamic test vectors. Add a `fuzz/` crate with nightly CI runs.

**Phase 8: structural refactor**
- [x] R8.1 Split `engine/lib.rs` and `mcp/lib.rs` into modules. Deduplicate clipping, quad→cubic elevation, CRC-32, the xref writer and crop marks.
